# friendbirthday_webapp

A fun personal birthday web app made for my friend, built to cheer her up with a playful neon birthday theme.

Live site: [https://friendbirthday-webapp.vercel.app/](https://friendbirthday-webapp.vercel.app/)

## About

This project is a cute, interactive birthday gift website with a phone-style layout, glowing pink visuals, sparkles, memories, letters, music, affirmations, and a small message space with positive responses.

It was made as a personal friendship project, not a commercial app. The goal is simple: make someone smile, feel appreciated, and have a little digital birthday surprise to open.

## Features

- Animated splash screens before entering the app
- Neon pink birthday home screen
- Birthday song page with a custom audio player
- Messages page with playful positive replies
- Affirmations page with encouraging reminders
- Letters page with cute popup letters
- Memories slideshow/gallery
- Reasons page with 100+ sweet reasons
- Profile picture upload saved locally on the device
- Mobile-friendly phone screen layout
- Hosted on Vercel

## Built With

- HTML
- CSS
- Vanilla JavaScript

No React, Vue, Bootstrap, or external frontend framework.
